Connect your Claude account

Usage comes straight from claude.ai using your browser's session cookie. It takes about a minute, and you don't need the Claude app.

  1. Open your usage page Make sure you're signed in to claude.ai.
  2. Turn on Safari's developer tools Safari → Settings → Advanced → tick Show features for web developers.
  3. Open DevTools → Network Press ⌥⌘IF12 and pick the Network tab. Press ⌥⌘ECtrl+Shift+E to open the Network panel. Press ⌥⌘I and pick the Network tab.
  4. Reload and find the “usage” request Type usage in the filter box, then reload the page (⌘RCtrl+R).
  5. Copy it Right-click usage → Copy → Copy as cURL (best — includes everything). Or click it → Headers → Request Headers and copy the cookie value. Right-click usage → Copy Value → Copy as cURL. Or click it → Headers → Request Headers → right-click Cookie → Copy Value. Right-click usage → Copy as cURL. Or select it → Headers and copy the Cookie request header.

Other ways to connect

Already use Claude Code on this computer? The plugin can read usage through its login instead of a cookie. On macOS you'll be asked once to let Stream Deck read the “Claude Code-credentials” keychain item.

🔒 Your cookie is stored only in Stream Deck's settings on this computer and is only ever sent to claude.ai. Treat it like a password: anyone with it can use your Claude account.
